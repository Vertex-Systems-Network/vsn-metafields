Inference: a polished, guided data-to-display journey may differentiate VSN better than merely duplicating Shopify's field creator. This is unvalidated. Next research: observe native flows and two themes, compare another direct competitor using primary material, interview representative merchants, measure definition-to-value-to-block completion, and check pinned API owner/type/scope matrix. Do not infer competitor implementation or user outcomes from marketing pages.

## Additional direct comparables (public listing claims, 2026-10-01)

- [Accentuate Custom Fields](https://apps.shopify.com/accentuate) advertises no-code customizable theme blocks and custom data workflows. This weakens any assumption that VSN's blocks alone are a unique differentiator.
- [Metafields2](https://apps.shopify.com/metafields2) advertises CSV import/export and editing across store resources. CSV is a category expectation, not evidence of a unique advantage.
- [Hulk Custom Fields Metafields](https://apps.shopify.com/metafields-manager-by-hulkapps) advertises bulk import and storefront display.

**Revised product hypothesis:** compete on a reliable guided definition → typed value → compatible, polished block workflow with transparent support boundaries and useful defaults. Validate the hypothesis with merchant task observation; public listings cannot establish usability, implementation quality or customer outcomes. Avoid marketing claims of universal support until the pinned API and actual stores are probed.
