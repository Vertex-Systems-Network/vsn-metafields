# Metafields expansion — research and market comparison

Status: initial evidence, not a validated market position (2026-10-01).

| Capability | Shopify native | Metafields Guru public claim | VSN current |
| --- | --- | --- | --- |
| Definitions | Standard/custom in admin | Definition management | Product, six types |
| Product bulk values | Native bulk product editing | Bulk editor/CSV | None |
| Storefront display | Theme dynamic sources | Storefront tools | None |

Primary references: [Shopify standard definitions](https://shopify.dev/docs/apps/build/metafields/list-of-standard-definitions), [types](https://shopify.dev/docs/apps/build/metafields/list-of-data-types), [native bulk editor](https://help.shopify.com/en/manual/custom-data/metafields/bulk-edit-metafields), [dynamic sources](https://shopify.dev/docs/storefronts/themes/architecture/settings/dynamic-sources), [app blocks](https://shopify.dev/docs/apps/build/online-store/theme-app-extensions/configuration). Comparable public feature claims: [Metafields Guru listing](https://apps.shopify.com/metafields-editor-2) and [vendor pricing](https://metafields.guru/pricing).

Inference: a polished, guided data-to-display journey may differentiate VSN better than merely duplicating Shopify's field creator. This is unvalidated. Next research: observe native flows and two themes, compare another direct competitor using primary material, interview representative merchants, measure definition-to-value-to-block completion, and check pinned API owner/type/scope matrix. Do not infer competitor implementation or user outcomes from marketing pages.
